 ├── components/       # Shared Components (Button, Modal กลาง)
 ├── lib/              # Config กลาง
 ├── features/         # ฟีเจอร์หลัก
 │    ├── inventory/   # ดึง components, types ที่เกี่ยวกับ inventory มาไว้ที่นี่
 │    ├── orders/      # ดึง components, types ที่เกี่ยวกับ orders มาไว้ที่นี่
 │    ├── pricing/
 │    └── customers/
 ├── store/            # เตรียมย้าย AppContext ไปใช้ Zustand (หรือคล้ายกัน)
 └── App.tsx
สรุปรายการไฟล์ (ย้ายจากไหน -> ไปไหน) ลงในแผน🛑 [WAIT FOR USER]แจ้งผู้ใช้: "ผมได้ร่างแผนการย้ายโฟลเดอร์และการทำ Feature-Sliced Design ไว้ใน refactor_plan.md แล้วครับ กรุณาตรวจสอบ หากต้องการให้เริ่มลงมือย้ายไฟล์ พิมพ์ 'อนุมัติ Phase 2'"Phase 2: การปรับโครงสร้าง Frontend (Frontend Restructuring)เริ่มสร้างโฟลเดอร์ features/ และย้ายไฟล์ Component, Type, Hook ต่างๆ ตามแผนที่วางไว้กฎสำคัญ:แก้ไข Path การ Import ของไฟล์ที่ได้รับผลกระทบให้ถูกต้องทั้งหมดไฟล์ใน Feature หนึ่ง (เช่น orders) ไม่ควร Import ข้อมูลข้ามไปดึง Type ภายในของ Feature อื่นโดยตรง ควรผ่าน index.ts (Public API) ของ Feature นั้นๆ(ถ้ามีเวลา/อยู่ในขอบเขต) เริ่มทะยอยแยก AppContext.tsx ออกเป็น Store ย่อยตามฟีเจอร์🛑 [WAIT FOR USER]แจ้งผู้ใช้: "การย้ายไฟล์และปรับโครงสร้าง Frontend เป็นแบบ Feature-based เสร็จสิ้นแล้วครับ (แก้ไข Path import เรียบร้อย) กรุณาทดสอบรัน Frontend หากหน้าเว็บเปิดขึ้นมาปกติ พิมพ์ 'อนุมัติ Phase 3'"Phase 3: การอัปเกรด Pricing Logic ใน Backend (Backend Pricing Engine)เข้าไปที่ไฟล์ admin-system/backend/pricing/engine.go (และไฟล์ Models ที่เกี่ยวข้อง)ปรับปรุงโครงสร้าง PrintJobInput ให้รับค่าเพิ่ม:Quantity (int) - จำนวนชิ้นงานSetupCost (float64) - ต้นทุนตั้งเครื่อง (Fixed)FinishingCost (float64) - ต้นทุนหลังการพิมพ์ (Variable)BaseProfitPct (float64) - % กำไรพื้นฐานปรับปรุงสูตรในฟังก์ชัน CalculateDynamicPricing (หรือคล้ายคลึงกัน):คำนวณ Variable Cost (ต่อ 1 ชิ้น): ค่าหมึก + ค่าเสื่อม + ค่ากระดาษ + Finishing Cost + (Waste 5%)คำนวณ Total Cost: (Variable Cost * Quantity) + Setup Costนำ Logic Volume Discount มาใช้: หาก Quantity >= 500 ลด % กำไรลง 10%, หาก >= 1000 ลดลง 20%คำนวณ Selling Price รวม และ Unit Price (ราคาต่อชิ้น)แก้ไข Handler/API ที่เรียกใช้ฟังก์ชันนี้ให้ส่งค่า Input ใหม่ให้ครบถ้วน🛑 [WAIT FOR USER]แจ้งผู้ใช้: "ผมได้ปรับปรุงสูตรคำนวณต้นทุนใน Backend เสร็จเรียบร้อยแล้ว รองรับ Setup Cost และส่วนลดตามปริมาณตามที่เราคุยกันครับ รบกวนทดสอบยิง API หรือคำนวณราคา หากตัวเลขออกมาถูกต้อง พิมพ์ 'จบงาน'"Phase 4: การตรวจสอบและสรุปผล (Final Review & Reporting)รันเช็ค Linter, Type Checker (ถ้ามี) ในส่วนที่แก้ไขไปตรวจสอบว่าไม่มี Breaking Changes ทิ้งไว้สร้างไฟล์ refactor_summary_report.md สรุปผล:📂 โครงสร้าง Frontend ที่ปรับเปลี่ยนไป🧮 สรุปสมการ Pricing Logic ใหม่ที่เขียนลงไป💡 คำแนะนำสำหรับการทำระบบ "แจ้งเตือนสต็อก" และ "Export Report" ในอนาคต🎉 จบกระบวนการแจ้งผู้ใช้: "งานทุกอย่างเสร็จสมบูรณ์ 100% แล้วครับ ผมได้ทำรายงานสรุปทั้งหมดไว้ใน refactor_summary_report.md ขอบคุณที่ใช้บริการครับ!"
