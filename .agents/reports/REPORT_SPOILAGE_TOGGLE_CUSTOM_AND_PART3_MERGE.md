# Report: Spoilage Toggle/Custom Input and Part 3 Ink/Machine Merge

## 1. ผลการดำเนินงาน (Execution Summary)
- **ปัญหาเดิม:**
  1. ในหน้าสรุปพาร์ทที่ 3 กล่องแจกแจงต้นทุนแยกข้อ 2 (น้ำหมึก) และข้อ 3 (จักรและอะไหล่) ออกจากกัน ทำให้ซ้ำซ้อน
  2. ในส่วนของค่าเผื่อเสียหาย (Spoilage) ไม่มีสวิตช์ Toggle เปิด/ปิด และไม่มีช่องกรอกตัวเลข % แบบ Custom ได้อิสระ อีกทั้งยังมีสูตร `Math.max(1)` บังคับแผ่นเผื่อเสียให้เป็นอย่างน้อย 1 แผ่นเสมอ
- **การแก้ไขที่ทำ:**
  1. **รวมข้อ 2 และ 3 ในพาร์ทที่ 3:** ยุบน้ำหมึกและเครื่องจักรเข้าด้วยกันเป็น **`2. ຕົ້ນທຶນການພິມ & ໝຶກ (Print & Ink Cost)`** บรรทัดเดียวจบ แสดงยอดรวมต้นทุนการพิมพ์ครบถ้วน
  2. **เพิ่ม Toggle เปิด/ปิด ค่าเผื่อเสียหาย (Spoilage Toggle):**
     - สามารถกดสวิตช์ Toggle เปิด/ปิด ได้อย่างสะดวก
     - เมื่อปิด (OFF): จำนวนแผ่นเผื่อเสียกลายเป็น **`+0 ແຜ່ນ`** ทันที ทำให้ใช้กี่แผ่นก็คิดราคาตามจริงเท่านั้น (เช่น พิมพ์ 1 แผ่น คิดกระดาษ 1 แผ่น = 190 กีบ ไม่โดนบังคับเป็น 380)
  3. **เพิ่มช่อง Custom Numeric Input สำหรับ % เผื่อเสีย:**
     - สามารถเลือก **Auto Tier** (คำนวณขั้นบันไดอัตโนมัติ)
     - สามารถคลิกเลือก Preset Chips ได้ (`3%`, `5%`, `7%`, `10%`, `15%`)
     - มีช่อง input **"ກຳນົດເອງ:"** ให้กรอกตัวเลข % ที่ต้องการได้ตามใจชอบ
