# Report: Unify Print Engine Cost and Set Default Labor to 0% in Quotation Engine

## 1. ผลการดำเนินงาน (Execution Summary)
- **ปัญหาเดิม:** 
  1. ตัวเลขต้นทุนหมึก 13 กีบ ขัดแย้งกับกล่องบนที่แสดง 153 กีบ เพราะแยกระหว่างค่าน้ำหมึก (13) กับค่าเครื่องจักร (140) ออกเป็นสองกล่อง ทำให้ดูเหมือนพิมพ์งานราคา 13 กีบ
  2. ต้นทุนรวมกลายเป็น 613 กีบ แทนที่จะเป็น 533 กีบ (กระดาษ 380 + พิมพ์ 153) เพราะระบบแอบคิดค่าแรง 15% (80 กีบ) เป็นค่าเริ่มต้นโดยที่ไม่มีกล่องแสดงค่าแรงในการ์ด
- **การแก้ไขที่ทำ:**
  1. **ยุบรวมการ์ดพิมพ์:** รวมกล่องหมึก (13 กีบ) และเครื่องจักร (140 กีบ) เข้าด้วยกันเป็น **`2. ຕົ້ນທຶນການພິມເຄື່ອງຈັກ (Print Engine: ໝຶກ + ເຄື່ອງຈັກ)`** แสดงยอดเต็ม **153 กีบ** พร้อมคำอธิบายย่อยชัดเจน
  2. **ปรับ Default ค่าแรงเป็น 0%:** ตั้งค่าเริ่มต้น `laborPercent: 0` (ไม่คิดค่าแรงซ้ำซ้อน) เพื่อให้ต้นทุนรวมเท่ากับ `380 (กระดาษ) + 153 (พิมพ์) = 533 กีบ` พอดีเป๊ะ
  3. **เพิ่มกล่องค่าแรงในการ์ดสรุป:** เพิ่มกล่อง `5. ຄ່າແຮງງານ & Setup (Labor)` ลงในการ์ดแจกแจงฟังก์ชัน ทำให้ยอดรวมของการ์ดทุกใบ (380 + 153 + 0 + 0 + 0) บวกกันได้ 533 กีบ ตรงกับยอดรวม 100% โปร่งใสและไม่มีเงินงอก
  4. **ปรับป้ายกำกับให้ชัดเจน:**
     - กล่องสรุปสีม่วงใน [QuotationPrintEngineTab.tsx](file:///Users/joun/Documents/GitHub/som-sing-phim-printing/admin-system/frontend/src/features/pricing/components/tabs/QuotationPrintEngineTab.tsx): เปลี่ยนเป็น `ສະຫຼຸບຕົ້ນທຶນການພິມເຄື່ອງຈັກ (Print Engine Cost)` และแสดงยอด `(ໝຶກ + ເຄື່ອງຈັກ)` ชัดเจน
     - การ์ดทางซ้ายใน [QuotationManager.tsx](file:///Users/joun/Documents/GitHub/som-sing-phim-printing/admin-system/frontend/src/features/pricing/components/QuotationManager.tsx): เปลี่ยนเป็น `ຕົ້ນທຶນຜະລິດລວມ/ໜ້າ (Total Cost)`
